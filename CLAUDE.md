# Polymarket Superforecaster — Project Memory

## Project Overview

A dashboard that visualises Polymarket prediction-market events, comparing the
**Market Crowd** probability line against an **Expert Superforecaster** line
generated algorithmically. A News Impact feed surfaces real-time events that may
influence predictions.

## Polymarket Gamma API — Data Schema

### Endpoints

| Endpoint                       | Method | Description                       |
| ------------------------------ | ------ | --------------------------------- |
| `/markets`                     | GET    | List all active markets           |
| `/markets/{id}`                | GET    | Single market detail              |
| `/markets/{id}/prices/history` | GET    | Historical price (probability)    |

### Market Object (response shape)

```ts
interface PolymarketEvent {
  id: string;                   // Unique event ID
  slug: string;                 // URL-friendly slug
  title: string;                // Human-readable title
  description: string;          // Full event description
  startDate: string;            // ISO 8601
  endDate: string;              // ISO 8601
  active: boolean;
  closed: boolean;
  markets: PolymarketMarket[];  // Outcomes (YES / NO tokens)
}

interface PolymarketMarket {
  id: string;
  question: string;
  outcomePrices: string;        // JSON string: e.g. "[0.62, 0.38]"
  volume: string;               // Total volume in USDC
  liquidity: string;            // Current liquidity depth
  clobTokenIds: string;         // CLOB token pair IDs
  active: boolean;
  closed: boolean;
}
```

### Price History Point

```ts
interface PricePoint {
  t: number;    // Unix timestamp (seconds)
  p: number;    // Probability [0, 1]
}
```

The Gamma API base URL is `https://gamma-api.polymarket.com`.

## Superforecaster Logic

### Core Concept

The "Expert Superforecaster" line is a **synthetic prediction** generated by
applying calibration techniques from the superforecasting literature (Tetlock,
2015) to the raw market probability. The key insight: prediction markets are
good but exhibit systematic biases:

1. **Favourite-longshot bias** — markets overweight unlikely outcomes and
   underweight near-certainties.
2. **Recency bias** — markets overreact to recent news then slowly revert.
3. **Crowd noise** — short-term volatility that isn't informative.

The expert line attempts to correct these biases.

### Brier Score

The scoring rule that evaluates prediction quality:

```
Brier Score = (1/N) * Σ (forecast_i - outcome_i)²
```

- Range: `[0, 1]` — lower is better.
- Perfect prediction = `0.0`, random coin flip = `0.25`, always wrong = `1.0`.
- We compute a **rolling Brier score** for both the Market line and the Expert
  line, comparing against resolved sub-events or interim ground truth.

### Inside View vs. Outside View

| View     | Source                                      | Weight |
| -------- | ------------------------------------------- | ------ |
| Inside   | Market's own price history, trend, momentum | ~40%   |
| Outside  | Base rates from similar historical events   | ~60%   |

The weighting shifts over time: early in a market the Outside View dominates
(reference class); as the end date approaches and more information arrives, the
Inside View gains weight.

### Expert Line Generation — Algorithm Choice

> **PENDING USER DECISION** — three candidate algorithms proposed below.
> The chosen algorithm will live in `src/lib/superforecaster.ts`.

#### Option A: Simple Extremization

Push market probabilities toward 0 or 1 to correct for known under-confidence:

```
p_expert = p_market ^ α / (p_market ^ α + (1 - p_market) ^ α)
```

Where `α > 1` (typically 1.5–2.5). Higher α = more extreme correction.

- **Pro:** Dead simple, one tunable parameter, well-studied.
- **Con:** Uni-directional — always pushes away from 0.5.

#### Option B: Base-Rate Anchoring with Bayesian Update

Start from a historical base rate for the event category, then update with
the market signal using a dampened Bayesian update:

```
prior       = base_rate(event_category)
likelihood  = p_market
p_expert    = (prior * likelihood) / ((prior * likelihood) + ((1 - prior) * (1 - likelihood)))
p_expert    = λ * p_expert + (1 - λ) * prior     // dampening
```

Where `λ` (lambda) controls how much we trust the market vs. the base rate.
Lambda increases as the market approaches its end date.

- **Pro:** Incorporates real outside-view data; naturally calibrated.
- **Con:** Requires a base-rate dataset per event category.

#### Option C: Time-Decay Smoothing with Extremization

Apply exponential smoothing to remove noise, then extremize the smoothed signal:

```
p_smooth(t)  = β * p_market(t) + (1 - β) * p_smooth(t-1)
p_expert(t)  = extremize(p_smooth(t), α(t))
```

Where:
- `β` = smoothing factor (0.05–0.2), controls noise filtering.
- `α(t)` = time-varying extremization that increases as end date nears
  (`α = 1 + k * (days_elapsed / total_days)`).

- **Pro:** Handles both noise and under-confidence; visually compelling line.
- **Con:** Two tunable parameters; lag on genuine information shocks.
